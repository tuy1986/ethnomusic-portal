# Этномузыковедческий портал — фронтенд v2

Прототип главной страницы по макету Frame 2621.

## Что изменено в v2

- hero-видео стало фиксированным фоном всего сайта (`position: fixed; inset: 0`), а первый экран занимает `100svh`;
- нижние секции полупрозрачные, поэтому видео остаётся видно при прокрутке;
- подключена векторная карта `Vector 79.svg`;
- карта масштабируется целиком и ограничивается высотой viewport, без обрезания;
- карточка народности больше не позиционируется возле точки: она находится в стабильной правой колонке карты, а на планшете/телефоне переносится под карту;
- при hover/focus/click активная группа окрашивается своим цветом, остальные точки приглушаются;
- исходная карточка «Нганасаны» сохранена как демонстрационная: 32 фото / 100 аудио / 15 публикаций;
- ссылка «Перейти» в блоке аудио временно ведёт на старый ASP.NET фонограммархив.

## Видео

`public/hero.mp4` — облегчённый 45-секундный web-preview, сделанный из предоставленного видео. Он зациклен и нужен, чтобы проект можно было быстро открыть/передать.

Для production лучше перекодировать полный исходник в web-версию (без аудиодорожки, H.264/WebM, разумный bitrate) и отдавать его статикой/CDN. Сам layout менять не нужно.

## Запуск Next.js

```bash
npm install
npm run dev
```

Открыть: `http://localhost:3000`

## Быстрый просмотр

`portal-prototype.html` — самостоятельный HTML-прототип, который использует файлы из папки `public`.
